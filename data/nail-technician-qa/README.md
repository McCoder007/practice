# Nail Technician Q&A

Minimal bilingual question-and-answer data for the future nail technician module.

- `questions.json` is the app-ready source: one array item per card/question.
- `index.ts` exports the same data with a small TypeScript type.
- `source-work/` contains the OCR, dedupe, translation, and audit artifacts used to build the final dataset.

Current app-ready item count: 227.
